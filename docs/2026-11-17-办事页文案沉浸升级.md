## 一、文案清单（办事页）

| 位置 | 原文倾向 | 现在 |
| --- | --- | --- |
| 问候语 `seasonGreeting` | 固定四季一句 | 随季节 + 资金紧/缺人/超员/把柄偏高切换 |
| 备忘区标题 | 每年做的事情 | 校园备忘（按年记下） |
| 待办 / 过问区标题 | 待办事项 / 今年过问 | 保留清晰名；副标题仍标「这一季 / 不占本季」 |
| 任务名 | 学科建设、基建… | **保留功能名**，不改成难懂文学标题 |
| 任务描述 `actionsCatalog` | 效果说明为主 | 部门来信式 1～3 句，说明为何发生 |
| 选系抉择 `deptPick` | 建设哪个系… | 建设名额给哪个系 / 新人落到哪个系 / 课题挂在哪个系 |
| 经费不足 / 本年已做 | 经费不够 / 今年做过了 | 账上暂时盖不住 / 这件事先搁下 |
| 抉择眉题 | 要你拍板 | 办公室来信 |
| 结果眉题 | 要你拍板 / 申报结果 | 事情有了下文（`kind: result`） |
| 建设/引进/国际/募捐/评估完成卡 | 偏结果句 | 保留数字，补部门口吻（教务处、人事处等） |
| 基建入口 | 盖哪一座 | 这一座盖什么；在建中 → 工地还没交出来 |

## 二、动态文案触发条件

配置入口：`CampusCopy`（`src/copy/campus-copy.js`）

| 条件键 | 判定 | 影响示例 |
| --- | --- | --- |
| `tight` | `funds < 16` | 建设/基建/募捐/升本任务描述更强调账本 |
| `careful` | `16 ≤ funds < 32` | 预留，当前多数走 default |
| `ok` | `funds ≥ 32` | 默认叙述 |
| `staff` | 任一系无在职教师 | 建设、引进强调缺带头人 |
| `heat` | `heat ≥ 40` | 巡察、冬日问候更紧 |
| `crowd` | 在校生 > 简易容量估算 | 基建、学生事务、春日问候提到拥挤 |
| `summer` / `winter` | 当前季 | 引进窗口、冬日稳住队伍 |
| `pending` 楼 | `campus.pending` | 基建描述改为「先别再开工」 |
| `cs≥50` | 计算机系实力 | 国际合作「联培」vs「更像访问」 |
| `tier` / `track` | 办学档次与路线 | 报课题可否、找政府是否提整合、升本任务叙述 |
| `focusTeach` | `tier ≤ 0` | 教学评估补教学；否则补短板叙述 |

选择顺序（`pickByState`）：`tight` → `staff` → `heat` → `crowd` → 季节 → `default`。

## 三、可复用结构

```text
CampusCopy.actionCopy(state, id, fallback)  → { name, desc }
CampusCopy.greeting(state)                  → { title, body }
CampusCopy.campusBlurb(state)               → string
CampusCopy.deptPickCopy(action, tier)       → { title, body }
CampusCopy.gateCopy("used"|"funds")         → { title, body }
CampusCopy.sectionCopy()                    → 区标题 / 眉题
```

`game.js` 中 `actionsCatalog` / `seasonGreeting` / `deptPick` / 办事 UI 区标题与场景眉题已接入；无 Copy 时回退旧文案。

## 四、一致性自检

- 任务名与费用、是否占用本季：仍由原 `cost` / `free` / `once` / `disabled` 控制，文案未改写费用数字。
- 选系选项的实力与「没有带头人」标记：仍来自真实 `dept` / `teachers`。
- 完成反馈中的 `+N`、退回经费、系名：仍由原逻辑拼接，只改前后套话。
- 未虚构「已发生」的论坛帖或新闻；备忘区仍只展示真实 `yearNotes`。
