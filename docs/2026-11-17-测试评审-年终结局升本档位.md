## 功能错

### L1. 升本后档位：条件未满仍显示「当前可申报」且申请按钮可点

- **位置**：`applySheet`（`tier>=1` 普通路径，约 4604–4622）；`disabled = used \|\| short`，**不含** `!ready`
- **现象**：212 页 tip 写「还有 1 项没到」（例：另有一个强系 0/1），英雄仍「当前可申报」，CTA「申请212 180万」可点；点后才进缺口页。
- **对比**：大专升本页已改为「当前可准备 / 查看升本缺口」。
- **建议**：与升本页对齐——未满时弱化文案、禁用或改成「查看缺口」；`disabled` 加入 `!ready`（或保留可点但改标签）。

### L2. 职业本科专硕页英雄文案恒为「当前可申报」

- **位置**：`applySheet` vocational 分支约 4599–4602
- **现象**：无论各点条件是否满足，一律「当前可申报」。
- **建议**：按可递点数写「可准备 / 可申报 · N 点」，或与缺口文案统一。

## UI 明显问题

### U1. 212 / 986 / 专硕页仍是旧 project-card + stepper

- **位置**：`projectCard` / `applyStepper`；实操 212、专硕页可见「1 条件准备 / 2 提交申报 / 3 等待结果」
- **现象**：与升本对比页（`apply-path` / `apply-compare`）和新简报/结局皮不一致。
- **建议**：后续用 Campus 条件列表重做，或至少去掉装饰性 stepper（它不反映真实流程状态）。

### U2. 升本成功庆祝卡顶栏仍写「要你拍板」

- **位置**：`topBar`：`state.scene.kind === "bulletin"` 才用「本年总结」，成功卡 `kind` 非 bulletin
- **现象**：升成普通本科时顶栏「要你拍板」，语义偏抉择而非结果。
- **建议**：成功/结果类 scene 用「申报结果」或沿用标题；或给 `finishAction` 的 scene 加 `kind: "result"`。
