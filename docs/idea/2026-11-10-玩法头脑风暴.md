# 玩法头脑风暴

2026-11-10。讨论稿。没有改 `d:\Program Files\code\new_game`，没有提交 git。

四份意见按策划、文案、研发、测试的职责分开交回。制作人对照 `game.js` 核对过下面用到的函数和数字，冲突处以代码为准。命名会话没能启动：派发时当前模型目录拒绝 `cursor-agent/grok-4.7-medium`，静态目录里的模型又报原生运行时不可用。本机 `cursor-agent models` 仍列出 `grok-4.7-medium`，命令行也处于登录状态。下面不是四个人在各自会话里写下的原文，是按这四个职责分别读完简报、角色说明和 `game.js` 之后交回的意见，再汇总。

核对过的事实：

- 一局 `YEARS = 14`，每年 `actionsLeft = 2`。存档键只有 `president-sim-v3`，每次重绘都会写入。
- 档次名是「大专 / 本科 / 211 / 985」。`TIERS[0].short` 的「高职」没有用在界面上。简报写的起点是高职。
- 学校栏有学术、教学、声誉、报考热度、经费、风纪、把柄风险、举报创伤。没有国际影响。211 要国际影响 22，985 要 40。寰球榜分数里，国际影响的系数是 0.5。
- 升格里「越低越好」的项只显示「达标 / 未达标」。
- 教师卡片把才华写成「学术」。职级是讲师、副教授、教授、学科带头人。
- `doRecruit` 写成 `greed > 78 ? 2 : 2`，引进的人职级都是教授。贪不贪只改一句台词。
- `doDonate` 花费 0，加经费和声誉。`doTeach` 固定教学 +8，说明仍写「升本看的就是这个」。`gates()` 从 211 起不再查教学。
- `storyBeat` 只在大约第 3、4、5、7、8、9、12 年各给一场。第 2、6、10、11、13、14 年没有这场主线。
- 没有主线、也没有把柄或审计时，年终从四张环境卡里抽。榜单卡只有「继续」，不改数。省里拨款和奖杯的选项都是加分。奖杯「抬学术」的说明写理学、工学，结算只加学校学术。医学拨款固定进医学，说明却写「最短的社会服务」。
- `leverageDemand` 随机三句要求，帮忙一律走 `resolveHelp`：职级 +1、系 +5、学术 -3、风险 +10。
- 年底经费另有一笔大约 +12。贪欲 ≥ 74、风纪 < 70 时，约 34% 把挪用标上，备忘里不写这个人的名字。
- `checkEnding` 在满年时先按 985、211 返回。「清誉调任」排在后面，而且正文写死「江湾」。世界一流的正文写「十四年后」，未满年也可能触发。
- 申报失败的句子写「右边和左边」。窄屏 980px 以下，三栏已经收成一列。

## 现在建议做

### 1. 把决策用到的数放到正在看的地方

玩家能看见的变化：学校栏出现国际影响。申报清单里，把柄风险、举报创伤、实名举报写出当前值和上限。教师卡片上的才华不再叫「学术」。教师被标成「账上有洞」时，上一份公报里有这个人的名字。申报失败改成「条件里还有没达到的」，不再写左右栏。

为什么适合现在的游戏：升格、榜单和举报已经在用这些数。玩家每年只有两次行动，看不见国际影响和上限，两次行动就变成对着红字试。

代价或风险：侧栏更挤。把上限写出来之后，玩家会按清单打勾，人物和把柄更容易被当成障碍数字。

### 2. 让没有主线的年份仍是一次交换

玩家能看见的变化：第 6、10、11、13、14 年，以及没有人物章的其他年份，年终至少有一个会让一栏上升、另一栏下降的选择。「今年的榜」不再只是把抬头上的寰球榜、区域榜再念一遍。省里拨款和奖杯要写明动的是哪一栏；说补最短的系，就补最短的系。奖杯若写理学、工学，结算就落到这两个系，或者说明改成只动学校学术。

为什么适合现在的游戏：人物线写到第 12 年的对手第三章就停了。后面的年份掉进四张环境卡，其中榜单不改数，拨款和奖杯只加分。14 年因此后半段变薄。

代价或风险：要新写的是现有 `scene` 和 `choose` 里的选项，不必新开系统。一年若总有大事件，双年职称评审会更长。空年补内容时，沿用已经在校的人和滨江，避免再开一条无关的收集线。

### 3. 让每年两件事在升格之后仍然不同

玩家能看见的变化：引进的人不再个个是教授。贪欲高的人，职级、当场的把柄或备忘里的后果，和贪欲低的人不同。升本之后，教学评估的按钮和结果改去推这一档仍在看的东西，例如学术、理学、风纪或国际影响，并写明不动的那一栏。国际合作在计算机不够强时，按钮上就能看见「更像访问」。

为什么适合现在的游戏：七个按钮用 14 年。教学评估在升本后仍只加教学，说明却继续讲升本。引进的职级分支写成了同一个数，人与人的差别只剩一句台词。

代价或风险：改动落在 `doRecruit`、`doTeach`、`doWorld`、`actionsCatalog`，不必改存档键。赶进度的人会少一个稳妥的教学按钮。引进一旦当场留下把柄，第一年的信封和后来的兑现会叠在一起，需要看一句备忘是否说得清。

### 4. 把柄的选项先写实际发生的事

玩家能看见的变化：来兑现时，选项写成现在真正发生的账：帮他，职级升一档，系变强，学术下降，风险上升，把柄还在。正文若仍写「审计别进这个系」或「留校名额」，结果条就出现审计或名额，而不是三句要求共用「帮，系变强」。

为什么适合现在的游戏：把柄是这一局的主交换。句子已经在许不同的忙，结算只有一笔。玩家会以为自己挡住了审计，账上却只是升职和学术水分。

代价或风险：只改句子，三句要求仍像换皮。若改成三笔不同的账，旧档里已经握把柄的人会突然碰上新后果。这一条要先由人选定做哪一种，见文末问题。

### 5. 建设名额和募捐要看得出代价

玩家能看见的变化：学科建设后，被削的那一两个系在结果里写明名字和减幅；可能的话，用该系带头人的一句短话代替只报减分。校友募捐若仍占两个名额中的一个，按钮上写明它挤掉的是另一件事，并给出除了「钱和声誉一起变好」以外的代价。若募捐不再占名额，玩家一年仍是两件要付费或付风险的事。

为什么适合现在的游戏：建设是 +8，连坐只有 -1 或 -2，十四年内短板掉得很慢。募捐花费为 0，年底还会再进一笔经费。两个名额里经常有一个是白拿。

代价或风险：连坐加重后，理工路线会更疼，文法 and 医学更难养。募捐若不再免费占名额，缺钱的年份会更紧，旧的「先募捐再建设」会断。数字改多少要单独拍板，见文末。

### 6. 公报先给原因

玩家能看见的变化：现有的「第 N 年公报」先放一句原因，例如哪个系垫底、谁开始挪用、国际影响为什么动了，数字跟在后面。不另做一页年终报告。

为什么适合现在的游戏：年底 `settleYear` 已经按六系改学术、声誉、经费和国际影响。玩家在两次行动里看不到这些被动变化，会觉得行动很轻、年底的数字自己在走。

代价或风险：公报变长。同一种短板若每年原句再出现，后几年仍会重复，所以原因句要带系名或人名。

## 以后再做

### 多存档

玩家能看见的变化：开局可以留下好几届，每条至少有校名、第几年、档次。

为什么以后再做：现在只有一个键，新开一局会盖掉上一届，而第一年的信封确实会拆成不同任期。多槽不改变每年两件事和空年。

代价或风险：列表若只有空号，窄屏上会再占一截已经很挤的开局。

### 人物或结局图鉴

玩家能看见的变化：打过的结局和记得的人可以在局外翻。

为什么以后再做：结局是互斥的任期卡，教师大多是开局随机的。图鉴现在会是一份空名单，也会把「清誉进不去」这种顺序问题摆成收集项。

代价或风险：要在唯一存档之外另存解锁记录。

### 随机种子

玩家能看见的变化：同一届可以按种子重来，巡察、拒绝、挪用和年终抽取能对上。

为什么以后再做：这些随机散在多个函数里，种子要写进存档。国际影响和门槛还没摆到屏幕上时，种子帮助复现，不帮助看懂。

代价或风险：要改存档里的状态形状。旧档需要缺省成「没有种子」。

### 手机上的整页重排

玩家能看见的变化：窄屏第一屏先是校名、年份和两个行动，六系的长说明可以收起。

为什么以后再做：980px 以下已经收成一列。真正挡阅读的是申报句和学校栏缺数，这两件放在上面的「现在建议做」。整页重排等行动列表的句子变短再做。

代价或风险：只改样式，不动规则。做早了，长说明仍会把代价挤到 11px、12px 的小字里。

### 设置

玩家能看见的变化：有一页可开关的选项。

为什么以后再做：现在没有文字速度、音量或难度字段。等种子或声音真要进游戏，再给它们一个位置。

代价或风险：单独做一页，会把开局的校名和「开始任期」拆散。

## 明确不做

### 再做一套自动存档

玩家能看见的变化：每次行动后再提示「已保存」。

为什么不做：每次重绘已经写入 `president-sim-v3`，开局已有「继续上一届」。第二套保存不改变两个行动和年终选择。

代价或风险：多一次提示，玩家会以为现在的继续不可靠。

### 撤销上一步

玩家能看见的变化：点完可以回到点之前。

为什么不做：收钱、巡察、不帮，都是点下去才知道结果。撤销等于把把柄和举报重掷一遍。

代价或风险：要为每一步留快照，和「收下就不能当没发生」对着干。

### 新手引导

玩家能看见的变化：开局或第一年多一层逐步说明。

为什么不做：开场已经有五条规则，第一年是「第一份递到你桌上的材料」。看不懂的是国际影响不在栏里、门槛不写数字。引导会把这些缺口用说明盖住。

代价或风险：玩家先上课，再开始任期。

### 另一页年终报告

玩家能看见的变化：公报之外再进一页年度总结。

为什么不做：`settleYear` 已经有公报。要改的是公报的读法，放在「现在建议做」。

代价或风险：评审、事件、公报、报告连着四次「继续」。

### 成就

玩家能看见的变化：任期卡旁边多一排徽章。

为什么不做：这一局的结果已经是任期卡。现在最稳的重复是募捐再加建设或国际合作，成就会把这条重复记成完成。

代价或风险：跨局成就和「再当一届就清掉唯一存档」对不上，还要另存进度。

### 音效

玩家能看见的变化：按钮和揭牌有声音。

为什么不做：这一局靠备忘和选项上的代价。声音不改变行动、门槛和把柄。

代价或风险：页面每次用整页重绘，声音只能外挂在点击上，还得先有设置页。

### 难度档

玩家能看见的变化：开局选简单或困难，门槛或行动次数跟着变。

为什么不做：升格清单和每年两次行动是这一局的结构。难度会把看不懂的门槛改成另一套数。

代价或风险：同一份规格要测多套 `gates()`，现有缺陷更难对照。

### 已读快进

玩家能看见的变化：见过的公告可以跳过。

为什么不做：重复的是同一套结算配不同句子，以及不改数的榜单卡。快进会把这些跳掉。应先把卡改成交换。

代价或风险：事件没有稳定 id，快进容易误跳仍带代价的选择。

## 需要拍板的问题

1. 校友募捐还占每年两个名额里的一个吗？若占，玩家能看见的代价是什么？若不占，这一年是否仍只做两件要付钱或担风险的事？
2. 把柄的三句要求，是只把选项改成对准现在的「升职、系变强、学术下降、风险上升」，还是改成审计、留校、名单三笔不同的账？
3. 升到本科之后，教学评估还留在行动列表里吗？若留，它改去推学术、理学、风纪、国际影响中的哪一项？
4. 学科建设的连坐现在是 -1 或 -2。要不要加重，让「一年一个名额」在十四年内真的养不起所有系？
5. 升到 211 或 985、并且一次都没把钱收进 `bribes` 的任期，要不要有自己的结局卡？现在会先返回「国家重点」或「顶尖学府」，「清誉调任」排在后面，正文还写死了「江湾」。
