# Cursor 接入任务：校园经营游戏素材库 v2.0

请先读取 `docs/asset-manifest.json` 与 `README.md`，再检查现有项目结构。按以下规则接入，不要擅自生成或替换美术素材：

1. 将本包 `assets/` 放入 `public/assets/game/`（如项目已有资源目录，沿用现有约定并保持路径一致）。
2. 根据 manifest 生成 `src/game/assets.ts`（或项目等价路径）的强类型资源注册表，至少导出 `buildings`、`characters`、`atlases`。
3. 在首页、学校、教师、办事、申报页面中优先复用独立建筑/人物 PNG；保持比例，图片用 `object-fit: contain`，禁止拉伸、裁头或替换成 emoji。
4. 图集只用于参考或后续切图，不得把整张图集当成单个图标、按钮或卡片背景。
5. UI 交互仍用真实 HTML/CSS/项目组件实现；图集内生成的文字可能不准确，所有中文标题、数值、按钮文字都必须使用真实文本。
6. 保持视觉规范：校园蓝白为主，薄荷绿代表成长/成功，奶油橙代表奖励/经营；圆角卡片、柔和阴影、统一描边和间距。
7. 完成后给出接入文件清单、页面引用位置、缺失资源清单和运行验证结果。不要虚构不存在的动画；人物目前只有静态 PNG。
