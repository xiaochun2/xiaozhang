## 二、动态文案触发条件

沿用办事页条件键（`CampusCopy._debug`）：

| 条件 | 判定 | 影响页面 |
| --- | --- | --- |
| `tight` | `funds < 16` | 学校顶栏、教师座右铭（间接经 pick） |
| `staff` | 任一系无在职教师 | 学校顶栏、教师座右铭 |
| `crowd` | 在校生 > 简易容量 | 学校顶栏 |
| `pending` 楼 | `campus.pending` | 学校顶栏优先改为工地叙述 |
| `heat` | `heat ≥ 40` | 教师座右铭 |
| `winter` | 当前季为冬 | 教师座右铭 |
| `review` | `year % 2 === 0` | 学校默认顶栏（双年评审） |
| `readyCount` / `pathReady` | 路线条件全满足 | 申报眉题与 CTA 分流（逻辑未改） |
| `missing` / `short` / `used` | 缺口数、经费、本年已报 | 升档 tip 句 |

选择顺序与办事页一致：`tight` → `staff` → `heat` → `crowd` → 季节 → `default`；在建楼在学校页覆盖默认句。

## 三、API 增量

```text
CampusCopy.schoolCopy(state)           → 标题 / 顶栏现状 / 建设空态
CampusCopy.peopleCopy(state)           → 座右铭 / 区标题 / 招聘培养考核文案
CampusCopy.applyCopy(state, ctx)       → mode: bachelor|master|ladder|d9
CampusCopy.pendingBannerCopy()         → 跨页待办条
CampusCopy.recruitOddsCopy(tier)       → 招聘档次口吻
```

无 `CampusCopy` 时全部回退旧字符串。

## 四、一致性自检

- 申报「材料已齐 / 可递」仅在 `pathReady` / 硕点全 ok 且经费够时出现，未虚构可申报。
- 学校「在建」只在真实 `campus.pending` 时出现。
- 教师空系、风险名单、才华分档仍来自真实 `teachers` 数据。
- 门槛 `item("综合评分", …)` 等标签未改写。
- 费用 `wan(14)` / `wan(6)` / 各档申报费仍由原逻辑渲染。
